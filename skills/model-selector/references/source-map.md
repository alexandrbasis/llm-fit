# Live source entrypoints

These are navigation routes, not an exhaustive or mandatory benchmark catalog. Discover current names, versions, methods, coverage and results at run time. A service linked here is not an endorsement of every metric it publishes. Follow maintained successors; if a page moves, find it through the owner's site. Label inaccessible evidence rather than guessing.

|---|---|

The video concentrates on engineering agents. Broaden discovery for other domains or missing capabilities; do not force those source families to cover every task.

## Supplemental discovery routes

| Entrypoint | When to follow it |
|---|---|
| [Terminal Bench project](https://www.tbench.ai/) | Owner's current evaluation and methodology when terminal tasks matter. |
| [Zapier benchmarks](https://zapier.com/benchmarks) | Owner's current evaluations when business-app actions and constraints matter. |
| [Arena](https://arena.ai/) | Discover current preference-evaluation categories and their methodology when human judgments are relevant. Follow leaderboard/research navigation. |
| [Hugging Face model catalog](https://huggingface.co/models) | Discover open checkpoints and official publisher model cards. Use each publisher's current documentation to verify identity, license, configuration and hardware requirements. |
| Official benchmark projects, papers and maintained repositories found by task-specific search | Fill coverage gaps for the actual domain, language, modality and operating environment. Read the owner's current methodology before using results. |

An index or leaderboard is a discovery aid. Trace findings to the source; multiple mirrors of one evaluation are not independent evidence. Check freshness and tested-model coverage before interpreting absence.
