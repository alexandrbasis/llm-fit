# Live source entrypoints

These are navigation routes, not an exhaustive or mandatory benchmark catalog. Discover current names, versions, methods, coverage and results at run time. A service linked here is not an endorsement of every metric it publishes. Follow maintained successors; if a page moves, find it through the owner's site. Label inaccessible evidence rather than guessing.

## Broad model discovery

Use these sources before choosing individual providers' documentation, following [discovery-coverage.md](discovery-coverage.md). No single catalog is the whole market.

| Entrypoint | What to discover and verify |
|---|---|
| [Artificial Analysis](https://artificialanalysis.ai/) | Current candidates across model owners, evaluation coverage, performance and pricing; follow the relevant methods and original model-owner pages. |
| [OpenRouter model catalog](https://openrouter.ai/models) and [catalog documentation](https://openrouter.ai/docs/guides/overview/models) | Models offered through this multi-provider service, their identities and available routes. Verify features, prices and settings on the actual route; a listing is not task-quality evidence or proof of account access. |
| [Hugging Face model catalog](https://huggingface.co/models) | Published checkpoints and model cards. Resolve the official publisher, exact variant and license; open weights may be available through hosted routes as well as local inference. Verify the intended route separately. |
| Current task-specific evaluation owners and model-owner release pages found by search | Discover specialists, recent releases and candidates missing from the catalogs above. Verify any claimed advantage using the task-matched methods. |

## Supplemental discovery routes

| Entrypoint | When to follow it |
|---|---|
| [Terminal Bench project](https://www.tbench.ai/) | Owner's current evaluation and methodology when terminal tasks matter. |
| [Zapier benchmarks](https://zapier.com/benchmarks) | Owner's current evaluations when business-app actions and constraints matter. |
| [Arena](https://arena.ai/) | Discover current preference-evaluation categories and their methodology when human judgments are relevant. Follow leaderboard/research navigation. |
| Official benchmark projects, papers and maintained repositories found by task-specific search | Fill coverage gaps for the actual domain, language, modality and operating environment. Read the owner's current methodology before using results. |

An index or leaderboard is a discovery aid. Trace findings to the source; multiple mirrors of one evaluation are not independent evidence. Check freshness and tested-model coverage before interpreting absence.

## Models, reasoning controls and prices

| Verification target | Live route |
|---|---|
| Model owner discovered in the broad pass | Find its current official catalog, model card, reasoning documentation, pricing and release notes. Resolve versions and ownership through primary sources. |
| Hosting provider or aggregator | Verify its current endpoint documentation, supported parameters, underlying model identity, availability and route-specific billing. |
| Application or local runtime | Verify the actual model selection, exposed controls, tools/plugins, quotas or hardware requirements. API compatibility alone does not establish a complete application integration. |

Follow pricing, availability, limits, releases and deprecations from the current official catalog. Verify the underlying model as well as any intermediary or application: access, controls and billing may differ. Product and documentation host names in these URLs identify services, not recommended model versions.

Store run-specific source links, dates and extracted facts in the evidence ledger. Keep this reference as a method for finding facts, not a copied market snapshot.
